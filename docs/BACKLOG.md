# Inkwell Product Backlog

Definition of Done: see [README.md](../README.md).

| ID | User Story | Priority | Points | Status | Notes |
|---|---|---:|---:|---|---|
| US-01 | As a visitor, I want to register an account, so that I can publish and interact with content. | High | 3 | Requirements Defined | See [use-cases.md](requirements/use-cases.md). |
| US-02 | As a registered user, I want to log in and stay logged in securely, so that I do not have to re-authenticate constantly. | High | 5 | Requirements Defined | See [use-cases.md](requirements/use-cases.md). |
| US-03 | As an author, I want to write and publish a post, so that readers can see my writing. | High | 5 | Requirements Defined | MVP uses plain text, manual publishing, and local-only autosave. |
| US-04 | As a reader, I want to browse a public feed of posts, so that I can discover new writing. | High | 3 | Requirements Defined | See [use-cases.md](requirements/use-cases.md). |
| US-05 | As a reader, I want to comment on a post, so that I can engage with the author. | Medium | 3 | Backlog | Requirements not yet defined in the repository. |
| US-06 | As a reader, I want to follow an author, so that I see their new posts more prominently. | Medium | 3 | Backlog | |
| US-07 | As an author, I want to see basic analytics on my posts, so that I understand my audience. | Low | 5 | Backlog | |
| US-08 | As a registered user, I want to reset my forgotten password, so that I can regain access to my account. | High | 5 | Backlog | New in Workshop 2. |
| US-09 | As an author, I want to edit a published post, so that I can correct mistakes or update outdated information. | Medium | 3 | Backlog | New in Workshop 2. |

## Story-Point Justifications

- **US-08 - 5 points:** This may take more work because it needs password reset links, email, and security checks.
- **US-09 - 3 points:** This should take less work because it builds on the existing system for creating posts.
